# HTML → xwl 转写：默认做法与平台惯例

> 本文件专收三类「skill 该拍、却不该散在正文里展开」的口径：
> **① 转写默认做法**；**② 平台默认值与惯例清单**（每条带出处与适用范围）；
> **③ 若干「源页有、wb 侧无现成对应物」的形态落法**。
> 读者对象是**零参照**的转写者 —— 只拿到一份 HTML、其脚本与控件注册表，
> 看不到任何现成 `.xwl` 时，也能据此把这几处做对。
>
> 本文件只管**「HTML → xwl 转写」这一件事**的取值与落法；
> 控件选型与骨架另见 [`controls.md`](controls.md)，SQL 与传参见 [`sql-fragments.md`](sql-fragments.md)，
> 事件 JS API 见 [`js-api.md`](js-api.md)。

## 一、证据面与强度分级

两条纪律：**每条都标出处**、**未独立复现的猜想不写成结论**。出处分四类，强度从强到弱：

| 强度 | 含义 | 例 |
|---|---|---|
| 机械判据 | 由控件注册表 / 本仓文档守卫 / 工具内置骨架直接决定，可复跑复核 | 注册表合法键、工具内置键序 |
| 语料实测 | 对某个工程语料做**全量**统计（按 JSON 解析后分类）得到的计数 | `renderer` 取值形态 函数体 vs 函数表达式 ＝ **22633 : 8** |
| 使用者告知 | 由使用者给出的平台事实 | `pageSize` 不填时的默认值 |
| 单臂选型 | 本轮实例测试中某一臂的选择，未经跨源验证 | 日期 `format` 取 `Y-m-d` |

> 口径（`语料实测` 的复现规则）：对全量 `*.xwl` 做 **JSON 解析后取 `renderer` 值**，按「该值能否作为**函数体**被解析器接受」分类；**以 `if` / `var` 等语句开头但内含 `return` 的写法并入「函数体」**。
>
> 证据面 = 一个真实工程（单个 wb 根、6 个真实页面，含页面与取数载体成对）的**本轮实例测试**结果。
> 凡标「使用者告知」者，**均未经本机独立复现**，引用时须保留这句限定。

## 二、转写默认做法（本类页面）

适用范围：**查询表单 ＋ 结果网格 ＋ 服务端分页 ＋ 后台占位**这一形态。

| 事项 | 默认做法 | 出处 | 证据强度 |
|---|---|---|---|
| 不可见参数（`display:none` 的输入 / 只作传参槽位的字段） | 用**其语义类型的控件**（文本框 `text`、下拉 `combo`、按钮 `button`）**＋ `configs.hidden:"true"`**；**不**造 `type:"hidden"` 控件 | 使用者纠正 ＋ 注册表取证 | 语料实测（`type:"hidden"` **0** 份 vs `"hidden":"true"` **398** 处）；注册表 `text` 合法键含 `hidden` |
| 列表分页 | **不填 `pageSize`**（框架自带默认「每页 100 条」）；分页条与服务端分页接线照做（`grid` 分页条 ＋ `dataprovider` 的服务端分页 ＋ `totalSql`） | 使用者告知 | 使用者告知（**未经独立复现**） |
| 必填校验 | **命令式写进触发按钮的 `click`**（内联判空 ＋ 提示）；**不加** `allowBlank` / `blankText` —— 查询工具条不是表单，声明不生效、只增噪音 | 使用者裁定 ＋ 本轮两臂对照 | 使用者裁定 |
| 被 `layer.open(type:2, content:url)` 打开的子页 | 子页落成**普通页面**；**窗口档位归父页**（源为 iframe 载完整文档） | 本轮实例测试（两臂独立判到同一结论） | 口径级（两臂独立一致 ＋ 第 2 层复核确认） |
| 源页「加载即渲染」（首屏直接出结果行） | `store` 要配 **`autoLoad:"true"`**；否则结果表永不加载。⚠️ **仅指「页面首屏加载即渲染」**；**窗口内嵌的 grid / store 另按 [`js-api.md`](js-api.md) 的建议**（常驻窗口内建议不 `autoLoad`） | 本轮实例测试 | 实测（行为缺口）；正面取证见文末待补① |

### 列表分页的最小接线

分页不是只填一个键 —— 「每页条数 ＋ 分页条 ＋ 总数 SQL」是**一组**，缺一不可。最小接线：

| 键 | 挂在哪个节点 | 作用 |
|---|---|---|
| `pagingBar` | `grid` 的 `configs` | 让网格显示分页条 |
| `pageSize` | 分页 `store` 的 `configs` | 每页条数 —— **本类页面不填**（框架默认每页 100，见 §三） |
| `autoPage` | `dataprovider` 的 `configs` | 声明服务端分页 |
| `sql` | `dataprovider` 的 `configs` | 列表数据 SQL（参数用 `{?名?}` 绑定） |
| `totalSql` | `dataprovider` 的 `configs` | 总条数 SQL —— 分页需要总数，**别漏** |
| `serverScript` | `module` 的 `configs` | 组装 SQL、把参数写进 request；`dataprovider` 用 `{#名字#}` 引用它 `setAttribute` 的值 |
| `url` | 分页 `store` 的 `configs` | 指向取数载体，**必须写成占位符**：`m?xwl=<模块>/…/xxxSql/queryXxx`（不带 `.xwl` 后缀；见 §三） |

最小取数片段（触发按钮的 `click`，把「必填校验 ＋ 取数」**命令式**合在一处）：

```text
if (Wb.isEmpty(app.<字段控件>.getValue())) { Wb.info('请填写…'); return; }
app.<store>.load({ out: app.<工具条> });
```

> `out` 用**工具条容器**作参数来源：增删条件控件不用改 JS（四条通路的规则见 [`sql-fragments.md`](sql-fragments.md)）。

### 决策归属三栏（谁拍）

同一件转写决策，**归属**要划清 —— 否则不同执行者会在同一处各自即兴（本轮两臂在「每页条数」上就各判一套、都错）。

- **① 默认做法表（skill 直接拍）**：见 §二 —— 其中属「决策归属」的三件是：**不可见参数**（用其语义类型控件 ＋ `configs.hidden:"true"`）、**列表分页**（不填 `pageSize`，接线见上）、**必填校验**（命令式写进按钮 `click`）。此处**不复制**。
- **② 必须回问用户（2 件）**：
  1. **真实后台取数**（表名 / 字段 / 接口）—— skill 拿不到后端；原接口若是 Java 端点，`bean` / `method` 只有用户知道。
  2. **页面标题 / 菜单名** —— 需与菜单注册（`WB_MENU`）对齐，而菜单注册**在工具范围之外**。
- **③ 不预设项（1 件）**：
  - **产物落点（模块路径 / 页面名）** —— **既不预设、也不回问**，留待**使用时由用户提供**。理由：转写阶段看不到 `wb/modules/` 的真实模块布局，预设必错；而它只影响交付落点、不影响转写内容，故**不必在转写时打断用户**。

> 本节与 [`SKILL.md`](../SKILL.md) 第八章的「决策归属」口径句**同源**：`SKILL.md` 只留一句 ＋ 指针，本文件承载三栏（避免同一结论两处维护）。

## 三、平台默认值与惯例清单

每条给「惯例 / 出处 / 适用范围 / 证据强度」。

| 惯例 | 出处 | 适用范围 | 证据强度 |
|---|---|---|---|
| `renderer` 的取值形态 ＝ **函数体**（`"return …;"`），**不是**函数表达式（`"function(v){…}"`） | 全量语料（解析后分类） | `column` 等需要回调的渲染键 | 语料实测 **22633 : 8** |
| `hidden` 的层级差异：页面**顶层**钥匙 `hidden` 是 **bool**；控件 **`configs` 级** `hidden` 是**字符串** | 语料实测 | 顶层钥匙 vs 控件 `configs` | 语料实测（`configs` 级字符串 **394 : 0** 裸布尔） |
| `m?xwl=` 后面**必须是占位符**（`<…>` / `…`；只有框架端点 `common/` 例外） | 本仓文档守卫原文 | 文档里书写取数 url 的示例 | 机械判据 |
| `pageSize` 不填 ⇒ 每页 **100** | 使用者告知 | 分页 `store` | 使用者告知（**未经独立复现**） |
| 列宽表达：`column` 用 `width`（px 字面量）或 `flex`（比例）；**`flex` 属 `column` / `panel` / `container`，不属 `grid`** | 注册表机械核对 ＋ 语料实例 | `grid` 的列与容器布局 | 机械判据（注册表 `grid` 88 个合法键**无 `flex`**） |
| 顶层 7 把钥匙与键序：`hidden, children, roles, title, iconCls, inframe, pageLink` | 工具内置骨架 | 新建页面 | 机械判据（`xwl.py new`）＋ 实测 |
| 控件节点键序：`configs, expanded, children, type`（有事件才追加 `events`） | 工具内置骨架 | 任意控件节点 | 机械判据 ＋ 实测（本轮 12 份产物仅出现此两种键序） |
| `store.params` 的形态 ＝ **bare-key 对象字面量字符串**（形如 `"{fldId:'…'}"`），**非** JSON 对象 | 语料实测 | `store` 节点的 `params` 配置 | 语料实测（JSON 对象形态真实工程 **0** 例） |
| 日期控件 `format` 取 `Y-m-d`（对齐 HTML5 `date` 的值形态） | 注册表合法键 ＋ 单臂选型 | `date` 控件 | 单臂选型（未做跨源统计） |

## 四、无现成对应物的形态：源页 → wb 侧落法

每类给「源页形态 → wb 侧落法 → 依据」。

### `th:if` 条件渲染

- **源页形态**：`th:if` 由服务端决定元素是否渲染（本轮实测散在表级与元素级共 **9** 处）。
- **wb 侧落法**：无服务端条件渲染对应物 ⇒ 落成**常驻节点 ＋ 运行期按数据显隐** —— 给节点 `configs.hidden:"true"` 作初值，在 `initialize` 或相关事件里按数据切换；条件表达式本身留 `TODO`（真实判定依赖取数结果）。
- **依据**：skill 对 `th:if` / 条件渲染**零口径**（本轮全量检索 0 命中）；本轮某臂「常驻 ＋ 运行期改文案」、另一臂「给初隐 ＋ 运行期显隐」，第 2 层复核判**给初隐**更贴。

### 按索引导出的 DOM id（一个控件模板 N 个实例）

- **源页形态**：模板循环内用行索引拼 DOM id（一个模板导出 N 个同名不同 id 的实例），逐行渲染。
- **wb 侧落法**：模板循环 ⇒ **网格行**（`grid` 的列由 `dataIndex` 取行值）；模板内每个「列位」映射为一个 `column`（字段列用字段名、勾选列用 `checkcolumn`、行键 / 计算列用对应类型列）。「一个模板 N 实例」的**非表格并排结构**本轮**未找到**平台对应物（未穷举注册表、未真机验证）⇒ 暂按「落成表格行 ＋ `TODO`」处理；复合键 / 计算列属近似，留 `TODO`。
- **依据**：skill 无「模板循环 → 网格行」映射口径（本轮全量检索无命中）；本轮某臂映射行键字段更多、另一臂少一列，复核判**多覆盖行键字段**更贴。

### 自定义遮罩 ＋ 倒计时

- **源页形态**：自绘遮罩层 ＋ JS 倒计时（定时器写剩余时间文案）。
- **wb 侧落法**：遮罩 / 弹层 ⇒ `window` 节点（`modal:"true"`）；倒计时无平台对应物 ⇒ 落成 `window` 打开后的事件 JS（`initialize` / `afterrender` 里起定时器、把剩余时间写进 `label` / `html`），或留 `TODO`；底部按钮条可做成 `dock` 工具条（`toolbar`，`dock:"bottom"`）。
- **依据**：[`js-api.md`](js-api.md) 只有「打开窗口」的遮罩选项，无自绘遮罩 / 倒计时口径；本轮两臂均落「`window` ＋ 按钮」，其中一臂把底部按钮条做成 `dock` 工具条、复核记「更细」。

### `layer` 的 `title:false` → wb 的 `header:false`

- **源页形态**：弹层选项 `title:false` ⇒ 不显示标题栏。
- **wb 侧落法**：`window` 节点的 `configs.header:"false"`。
- **依据**：注册表 `window` 合法键含 `header`；skill 未记载这条映射；本轮某臂在其各 `window` 上均设 `header:false`、另一臂未设（属窗口口径，可与上一类合并）。

### 被外部弹窗打开的子页自身形态

- **源页形态**：子页由父页以 `layer.open(type:2, content:url)` 以 iframe 载入**完整文档**。
- **wb 侧落法**：子页落成**普通页面**（自身**不带** `width` / `height` / `header` 等窗口档位）；弹窗尺寸与档位**归父页**的 `window` 节点。
- **依据**：两臂独立判到同一结论，第 2 层复核判「对」；子页产物复核确认「不带窗口档位」。

### 源页「加载即渲染」⇒ `store` 配 `autoLoad`

- **源页形态**：首屏由服务端直接渲染出行、无独立取数动作。
- **wb 侧落法**：`store` 配 `autoLoad:"true"`。⚠️ 本做法**仅指「页面首屏加载即渲染」**；**窗口内嵌的 grid / store** 另按 [`js-api.md`](js-api.md) 的建议（常驻窗口内建议**不** `autoLoad`）。
- **依据**：本轮某臂子页 `store` 无 `autoLoad`、全页无取数调用 ⇒ 复核判**结果表永不加载**（行为缺口基线）；另一臂配 `autoLoad:"true"` 更贴源。

### 能力边界：`a` 控件无 `target` 键

- **源页形态**：外链 `<a href target="_blank">`。
- **wb 侧落法**：外链**不转写**、**原地保留链接**（不为其设计控件或窗口档位）；平台 `a` 控件**无法表达**「新窗口打开」（其合法键无 `target`）。
- **依据**：注册表 `a` 的 **14** 个合法键无 `target`；本轮某臂把外链合并成一个 `a` 节点并丢掉 `target`、另一臂原地保留两个带 `target="_blank"` 的 `<a>`（复核判后者更贴「原地保留」口径）。
